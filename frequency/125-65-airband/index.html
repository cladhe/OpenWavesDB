This draws on 15 independent official sources across 16 countries (Belgium and Luxembourg share one source, since Luxembourg's only aerodrome is published inside Belgium's AIP):
• United States: FAA 28-Day NASR Subscription, Frequency Data (FRQ) CSV (faa.gov NASR_Subscription), cycle effective Jul 9 2026. The FAA's own FREQ_USE field is a very long tail (almost 7,000 distinct raw values, mostly one-off named arrival/departure fix frequencies), so each was bucketed into the class categories above by a pattern-matching rule, with the original raw designator kept in the Days/Info column whenever it isn't already obvious from the class. A frequency marked "receive-only" means the outlet only listens on that channel (some remote FSS relays, for example).
• France (including its overseas territories): SIA/DGAC XML_SIA aeronautical database export, AIRAC cycle 07/26 effective Jul 9 2026 (sia.aviation-civile.gouv.fr). En-route/area control-center sector frequencies aren't tied to a single airport in the source data, so they're out of scope for this airport-keyed search and were excluded. A small number of source records (80 of 1,741 raw entries) had a dangling service reference in SIA's own export; 59 were recovered by matching the airport name embedded in the record, and 21 were left out. One airport code, TFFG (Saint-Martin/Grand Case), is published independently by both the FAA and SIA, so it appears under both countries rather than merged, since it's genuinely documented by each authority.
• Saudi Arabia: GACA/SANS eAIP, AIRAC AIP AMDT 07/26 effective Jul 9 2026 (aimss.sans.com.sa), the "ATS Communication Facilities" table published for each of the country's 61 aerodromes. 121.5 MHz entries are reclassified as EMERG no matter which section of the source table lists them, since it's the universal guard frequency rather than a service specific to that section; everything else is bucketed by the source's own service designation. HF-band and UHF military frequencies published alongside the VHF ones are excluded, since they're out of range for this band.
• Brazil: DECEA/AISWEB eAIP, AIRAC AIP cycle A 11/2026 effective Jun 11 2026 (aisweb.decea.mil.br), the "ATS Communication Facilities" table published for 50 of the country's aerodromes (the ones with a detailed AD 2 entry in this AIP; one of those 50, SBTT, has no such table and contributes no entries). Each source cell is bilingual, a Portuguese line followed by an English line, and only the English line is kept. Approach/en-route control isn't published per-airport here, so, as with France and Saudi Arabia, it's out of scope for this airport-keyed search. An "INFO"/"Operations" coordination channel published at some airports doesn't fit any ATC class and is bucketed as OTHER. 121.5 MHz rows are reclassified as EMERG the same way as Saudi Arabia's.
• Belgium & Luxembourg: skeyes eAIP, cycle effective Jul 9 2026 (ops.skeyes.be), the "ATS Communication Facilities" table for 33 aerodromes (of Belgium's much longer full list, only these have a published AD 2.18 table), including Luxembourg's only aerodrome, ELLX. That one is published inside Belgium's AIP rather than separately, and it's shown here under country "Luxembourg" while the rest are listed as "Belgium". A frequency cell can list a paired VHF+UHF value (a civil/military guard pair, for example); each is parsed out as its own entry, with anything outside 108-137 MHz dropped. Footnote and cross-reference rows (source notes, not real frequency rows) are excluded.
• Netherlands: LVNL eAIP, AIRAC AMDT 07-2026 effective Jul 9 2026 (eaip.lvnl.nl), the "ATS Communication Facilities" table for each of the country's 21 published aerodromes.
• United Kingdom: NATS eAIP, cycle effective Jul 9 2026 (aurora.nats.co.uk), 111 aerodromes. Hidden metadata spans embedded in every data cell are stripped before parsing, and blank continuation rows (with no rowspan) are forward-filled from the prior row. The source's own broad "OTHER" category (spanning non-ATS fire/emergency channels through small-field advisory radio) is kept as OTHER rather than force-split into classes the source itself doesn't distinguish.
• Ireland: IAA/AirNav Ireland eAIP, cycle effective Jun 11 2026 (airnav.ie), same template family as the UK's, 22 aerodromes. This source uses "-" rather than "NIL" for empty fields.
• Portugal: NAV Portugal eAIP, current cycle (ais.nav.pt), 18 aerodromes (including Azores and Madeira). Table width varies by airport: some cram multiple frequencies into one cell, others use one frequency per row, and both formats are handled.
• Czech Republic: ANS CR eAIP, current cycle (aim.rlp.cz), 11 aerodromes.
• Hungary, Estonia, Slovenia, Bosnia and Herzegovina, and Albania: each country's own ANSP eAIP (HungaroControl, EANS, Slovenia Control, BHANSA, and ALBCONTROL respectively), each at its current cycle, covering every aerodrome each one publishes with a communications table (8, 6 of 8, 4, 4, and 2 aerodromes respectively, small totals because these countries' AIPs only detail controlled/IFR-relevant aerodromes, not the full national airfield inventory the way the FAA's data does).

Airport codes: each country's own register gives an unambiguous primary identifier (an FAA code for the US, an ICAO code for every other country), shown first. Where available, a second code is shown alongside it: the ICAO code for US airports (from the FAA's own APT_BASE register, though not every airport has one) or the IATA code elsewhere. No other country's own aeronautical register publishes IATA codes, since those are airline/commercial codes rather than aviation-authority data, so those come instead from the public OurAirports ICAO/IATA crosswalk. Coverage varies a lot by country; small strips, military fields, and other non-commercial airports typically aren't assigned a second code at all.

Two categories are deliberately excluded across every country, as out of scope for this band: NAVAID frequencies (VOR/ILS/NDB, navigation beacons rather than voice communication) and military UHF frequencies (225–400 MHz, a physically different band from civil VHF airband, used at joint-use military/civil fields). All entries are shown as continuously available, since published operating hours are inconsistent free text in the source and aren't force-fit into a schedule here.

Beyond those 16 official sources, this table is supplemented with OurAirports' public-domain (Unlicense) community-contributed frequency data for airports and countries outside the 16 above. That's genuinely useful for coverage, but it isn't government-verified the way the rest of this table is, so treat those specific entries with an appropriate grain of salt. In the very rare case where the same short code is shared by two entirely different real-world airports, each is listed as its own entry with its country shown in the label so they can be told apart.
